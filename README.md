# Matheus Lima Fotografias - Site Oficial

## 📌 Sobre o Projeto
Este projeto é o site oficial de **Matheus Lima Fotografias**, desenvolvido para exibição do portfólio, agendamento de serviços fotográficos e interação com clientes através de um chat com inteligência artificial. O site é de uso **exclusivamente interno** e não pode ser copiado, distribuído ou utilizado para outros fins sem autorização.

## 🚀 Funcionalidades
- 📸 **Galeria de fotos**: Portfólio organizado por categorias (Sensual & Casual, Gastronomia, Eventos & Festas).
- 📅 **Agendamento Online**: Opção para marcar ensaios fotográficos e eventos.
- 🤖 **Chat Inteligente**: Persona virtual de Matheus Lima para auxiliar clientes na escolha do serviço ideal, locações e melhores condições para fotografia.
- 📱 **Contato Rápido**: Integração com WhatsApp e redes sociais.

## 🛠️ Tecnologias Utilizadas
- **HTML, CSS, JavaScript** para o frontend responsivo.
- **API Gemini 1.5 Flash** para chatbot interativo.
- **Bolt.new** para automação da criação do site.

## ⚙️ Configuração da API do Chat
Para integrar a IA de atendimento, utilize a seguinte configuração na aplicação:

```python
API_URL = "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash-latest:generateContent"
API_KEY = "SUA_CHAVE_DE_API_AQUI"
```

Substitua `SUA_CHAVE_DE_API_AQUI` pela chave correta de acesso à API.
